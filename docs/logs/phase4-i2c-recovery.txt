What the log shows:
- Three attempts 100 ms apart (65460, 65560, 65660 ms), then a bus reset requested from T3; the reset returns ESP_OK and T1 is told.
- A failed cycle is still logged, with ERR incremented and the markers !TIME (no RTC reading) and !SENS (stale values).
- The log keeps one line every 5 s through the whole failure: a failed cycle takes about 220 ms.
- When the wire is back, the next cycle succeeds: "sensor is back", the error state is cleared, ERR stays at the last count.
- The error code is ESP_ERR_INVALID_STATE: this is what the ESP-IDF I2C driver returns for a device that does not answer.
